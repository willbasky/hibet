# Архив документов hewts

Здесь лежат исторические документы. Они **не обновляются** и описывают прошлые
снимки состояния. Живые документы — в `../../hewts/`:

- `DESIGN.md` — устройство и принципы;
- `SPEC.md` — нормативные требования;
- `ROADMAP.md` — что осталось.

Если архивный документ противоречит живому, прав живой.

| Документ | Что это | Снимок |
|---|---|---|
| `ROADMAP-waves.md` | полный план волн 0–10 и журнал работ | 05.11.2026 |
| `REFERENCES-FEATURES.md` | матрица фич hewts против эталонных конвертеров | 16.10.2026; статусы устарели |
| `REFACTOR-AST.md` | контракт и журнал рефакторинга AST | закрыт 29.10.2026 |
| `REFACTOR_REVIEW.md` | ревью шагов 0–4 | 22.10.2026 |
| `REFACTOR-ARCH-REVIEW.md` | архитектурная оценка рефакторинга | 22.10.2026 |

Решения, которые остаются в силе, описаны в `DESIGN.md` и `SPEC.md`; архив —
источник истории. Ссылки внутри архивных файлов могут вести на старые имена —
это ожидаемо.
