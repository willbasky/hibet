# Документация hibet

Репозиторий содержит три пакета:

- **`hewts`** — библиотека конверсии тибетского письма Wylie ↔ Unicode и
  проверки правописания. Чистая: без IO, без словарей, без переводчика.
- **`hibet`** — движок переводчика: словари, `Env`, чистый `getAnswer`;
  конверсию письма берёт у `hewts`.
- **`hibet-cli`** — консоль: `App`, `Cli`, `Shell`, `Pretty` и exe `hibet`.

## С чего начать

1. `ARCHITECTURE.md` — как пакеты связаны и как идёт поток данных.
2. `hewts/DESIGN.md` или `hibet/DESIGN.md` — устройство нужного пакета.
3. `hewts/SPEC.md` — что `hewts` обязан делать. Это единственный нормативный
   документ.
4. `hewts/ROADMAP.md` или `hibet/ROADMAP.md` — что дальше.

## Карта

| Документ | Роль |
|---|---|
| `ARCHITECTURE.md` | общий: пакеты, зависимости, поток данных, модули |
| `TERMINOLOGY.md` | словарь проекта: слог, стек, роль, нотация, корпус |
| `TASKS.md` | очередь работ T1–T26 со статусами и критериями |
| `hewts/DESIGN.md` | устройство hewts: три слоя, модель слога, границы |
| `hewts/SPEC.md` | нормативные требования S1–S12, открытые пункты, долги |
| `hewts/ROADMAP.md` | что осталось у hewts и в каком порядке |
| `hibet/DESIGN.md` | устройство движка: Env, Dictionary, Translator |
| `hibet/ROADMAP.md` | что осталось у hibet |
| `../hewts/README.md` | README пакета hewts |
| `../hibet/README.md` | README переводчика |
| `../hewts/test/README.md` | индекс тестов hewts: модуль → источник ожиданий |
| `archive/` | исторические документы, не обновляются |

## Правила

- Нормативный текст один — `hewts/SPEC.md`: требования и статусы. `ROADMAP`
  задаёт порядок, `DESIGN` — устройство; они не переписывают требования.
- Живые документы описывают текущее состояние. История работ живёт в
  `archive/` и в `CHANGELOG.md` пакета.
- Ссылки относительные, от файла, в котором стоят.
