# Дорожная карта hibet

Живой план переводчика. Подробная постановка задач — в `../TASKS.md`.
Устройство — `DESIGN.md`; конверсия — в пакете `hewts`.

Снимок: 11.11.2026.

## Где мы сейчас

- Перевод работает на Wylie и на тибетском Unicode.
- Словари: 59 файлов, около 103 МБ; чтение строгое в зелёных потоках, разбор
  `parMap` идёт в фоновом потоке и форсится до NF до `putMVar` (T29, T8).
  Тёплая загрузка `Env` — 253 мс с `-A16m` (386 мс с `-A4m`), холодный кэш —
  259 мс, `maximum residency` около 160 МБ, RSS 542 МБ. Первый запрос после
  готовности `Env` стоит столько же, сколько второй (0,04–0,09 с после паузы).
- Поиск: `searchTranslation` — `HMS.lookup` по каждому словарю,
  последовательно; `parList` убран (T9).
- Эффекты сняты (T24): `makeEnv*` возвращают `IO (Either HibetError Env)`,
  фоновая загрузка идёт через `Ki.scoped`/`Ki.fork`; `effectful` и
  `path`/`path-io` ушли из библиотеки.
- Unicode-вход покрыт матрицей (T5). Легаси-ключи (`bha` против `b+ha`, `gnad`
  против `gand`) юникод-запрос находит через таблицу `hibet-data/key-aliases.tsv`
  (T10): канонический ключ кладётся рядом с легаси при загрузке.
- Данные вынесены из пакета в `hibet-data/` (T25, шаги 1–7): resolver
  `--data-dir` → `HIBET_DATA_DIR` → XDG, `hibet data status`, манифест с
  версией и sha256, `data-files` удалены, `hibet-tools` генерирует и проверяет
  манифест, `hibet data install`/`update` ставят его в XDG, `just data-release`
  собирает архив для GitHub Releases. `cabal sdist` — около 20 КБ.
- CLI: `shell`, `show names`, `show meta`, `om`, `data status`/`install`/
  `update`, глобальный `--data-dir`. Консоль вынесена в пакет `hibet-cli`
  (T2): `hibet` — движок без Haskeline и optparse.
- Обновление словарей — `hibet-tools` (T12): `just update-dicts`,
  `just update-dicts-check`, `just generate-key-aliases`; bash/python/curl не
  нужны. Alias-таблица пересобирается в том же процессе.
- Машинного интерфейса нет: только интерактивный `shell`; это T26.
- Юникод-вход проверен матрицей в `hibet-env`: пунктуация, пробелы, переносы,
  смешанный текст и ошибочные слоги дают те же статьи, что Wylie-ключ (T5).
- Issue: 17 открытых; T11 закрыт — 3 закрыты, 14 сведены в T13–T23.

## Чего не делаем

- **Переводчик в браузере без сервера.** 103 МБ словарей и Haskeline-цикл
  делают это бессмысленным. В браузере имеет смысл только конвертер hewts —
  см. `../hewts/ROADMAP.md` и T4.
- **Свою конверсию письма.** Единственная точка — hewts; дублировать грамматику
  в переводчике нельзя.
- **Второй формат словарей.** Пока `ключ|перевод` хватает, новый формат не
  вводим.

## Данные и риск

Словари — самые тяжёлые данные репозитория. Они больше не входят в пакет:
`hibet-data/` лежит в корне репы, установленный бинарь ищет его через `--data-dir`,
`HIBET_DATA_DIR` или `$XDG_DATA_HOME/hibet/data`. Публикация `hibet` на Hackage
теперь не упирается в 103 МБ; CLI без данных требует флаг или переменную.
Осталось опубликовать собранный `just data-release` архив в GitHub Releases
основной репы (T25, шаг 8). `hewts` — T17.
